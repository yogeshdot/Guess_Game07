# Guess the Number Game

A simple browser game where you try to guess a randomly chosen number from 1 to 10.

## How to Play

1. Open `indx.html` in your web browser.
2. Enter a number between 1 and 10 and select **Submit Guess**.
3. Use the higher or lower hint to help with your next guess.
4. You start with 10 points and lose one point for each incorrect guess.
5. Select **Play Again** to start a new game.
